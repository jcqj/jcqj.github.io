Plataforma web para joyería con arquitectura por capas y catálogo dinámico

Solución web e-commerce desarrollada en entorno colaborativo (Bootcamp). Integración de lógica de servidor en Java con Spring Boot para la gestión de productos y persistencia de datos, conectada a una interfaz web responsive y enfocada en la experiencia de usuario.

JavaSpring BootJavaScriptHTML5CSS3Bootstrap 5PostgreSQL
  • Problema y Enfoque: Necesidad de estructurar una plataforma atractiva para la exhibición de joyas finas, garantizando una navegación fluida entre catálogo, sección institucional y contacto.
  • Aporte Técnico: Colaboración en el modelado de la base de datos y lógica de backend con Java/Spring Boot. En el frontend, desarrollo de componentes reutilizables (cards de producto) y afinación de efectos visuales interactivos con CSS/Bootstrap.
  • Resultado: Despliegue de una plataforma funcional, código modularizado y estructurado, y trabajo en equipo coordinado para la entrega de un producto web integral.
